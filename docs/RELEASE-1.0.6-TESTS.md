## 限制与安装兼容性

此前安全软件仍在运行时，Windows 曾拒绝启动安装 EXE（WinError 5），随后文件从输出目录消失；普通权限产品测试的 pnpm 初始化也曾失败。用户退出 360 后，重新生成的安装包和干净数据目录首次启动全部通过。没有安全软件拦截日志，不能据此确定每一次失败的具体来源；安全软件开启时的安装兼容性仍未验证。

自动安装使用验收模式，不改真实桌面快捷方式与卸载注册；产品测试不切换用户桌面，不读取真实账号、Cookie 或模型密钥。所有修改均限于一次性测试安装和数据目录。

未覆盖用户故障电脑完整的独立 DSH 桌面共存，也未测试真实在线模型回复。双后端通过不代表原机冲突已经完全解决。

本版本未重新编译 Chromium，沿用已构建的内核；本次没有执行新的原生页面就绪专项或热升级专项，不把旧版专项结果计入本版测试数量。公开发布文件附有精简验收报告与 SHA-256 校验值。
