# v1.0.5 发布测试说明

2026-11-11 在构建机使用最终的 `BlueBean-Setup-1.0.5-Windows-x64.exe` 完成独立安装及功能验收。测试使用一次性安装目录和独立数据，不访问真实账号、环境或会话。

## 安装与运行时

- 普通用户 Medium Integrity 权限安装成功，安装器退出码为 0，用时约 40.31 秒；沙箱访问权限配置成功，无需重启系统。
- 已安装文件与打包载荷逐个检查 SHA-256，共 13,890 个文件，无差异。一次失败重建改写了载荷目录中的启动器时间戳，校验前从重建之前保留的独立载荷副本恢复了原始启动器基线；该副本与最终安装结果一致。
- 最终 EXE 与原生启动器的 Windows 产品版本及文件版本均为 1.0.5；安装器、启动器和浏览器图标均与蓝豆图标一致。
- 私有 Python、动态导入依赖、产品模块、DSH 初始化、Chromium 沙箱渲染、安装文件完整性级别和沙箱访问权限检查通过。
- 带空格路径的原生启动器及自带 pythonw 启动链路通过；插件模板启动后保持不变，两个测试数据目录中的插件凭据互相隔离。
- 载荷隐私检查通过：安装包不包含开发环境、账号、Cookie、个人配置或凭据。公开源码审查检查 194 个文件，未匹配已知开发凭据或要求移除的个人署名。

## 产品功能

- 在未展示的独立 Windows 桌面上通过 26 项产品检查：无控制台窗口、首次启动空环境列表、初始化提示、API Key 输入可达、首次配置完整显示、助手与工具栏各 8 次收放、环境保存和激活、自动化通道、重复启动复用、重启后数据保留等。
- 本机浏览器就绪约 1.047 秒，后台助手就绪约 5.984 秒。这些时间仅代表本机本次测量。
- 安装版浏览器通过默认和软件解码两种配置下的 10 项本地播放回归：MP4 H.264/AAC、720p、MSE 合流、MSE 分轨及 VP9/Opus，检查时间轴推进、解码帧和跳转。

## Agent 稳定性与速度

- 开发目录和公开源码目录分别通过 186 项 Python 回归测试；两个目录的插件各通过 19 项检查，覆盖 24 个工具注册和临时 profile 中的真实 HTTP 调用。
- 真实桥接进程回归通过：空闲旧版本替换、控制端口和令牌保留、并发替换单实例、已加载版本确认、当前版本复用及忙碌版本保留。
- 安装版内核与生产后端通过 17 个原生场景记录，包括慢资源、延迟目标、遮挡、移动、局部出屏、可信输入、只读输入、过期文档、重定向和 SPA 结果。
- 连续 20 次导航、观察和提交，每次只提交一次；5 次过期元素编号尝试均在发送输入前拒绝。
- 本地慢资源场景中，背景资源完整加载约 3.03 秒，业务点击完成约 0.33 秒。这是局部确定性测试，不代表所有网站或完整 Agent 任务的提速幅度。

## 测试边界与已知现象

- 本机此前在 360 运行时出现安装 EXE 启动被拒绝、文件消失，以及 DLL 重命名返回 Windows 错误 5。旧的 1.0.4 也能复现。用户退出 360 后，同一个 1.0.5 安装包完成安装和产品验收；未验证本机重新开启 360 后是否仍能正常安装，也未定位到具体防护模块。测试没有自动关闭安全软件、添加排除项或修改系统安全策略。
- 最终安装使用 `/ACCEPTANCETEST=1`，不改动使用者现有快捷方式及卸载登记；未覆盖全新实体电脑上的交互式安装向导、系统登记和卸载全流程。
- 第一轮原生测试无法读取输入桌面，报告将该检查明确记为不可用；最终产品测试中桌面检查可用并通过。测试没有调用桌面切换或全局键鼠输入。
- 本轮没有调用在线 DSH 模型，因此不代表完整模型任务成功率。视频回归不保证所有外部视频网站、DRM 或第三方服务均可用。
