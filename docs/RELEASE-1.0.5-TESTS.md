# v1.0.5 发布验证（2026-11-11）

本版本包含 Windows 启动兼容、页面就绪等待、过期元素保护、观察性能优化，以及旧桥接进程识别与刷新。

## 已通过

- 开发目录与公开源码目录分别通过 186 项 Python 回归测试。
- 两个目录的 DSH 插件检查各通过 19 项，覆盖 24 个工具注册和临时 profile 中的真实 HTTP 调用。
- 真实桥接进程测试通过：空闲旧版本替换、端口和令牌保留、并发替换单实例、已加载版本确认、当前版本复用和忙碌版本保留。
- 生产后端与桥接的原生浏览器回归通过 17 个场景记录，覆盖慢资源、延迟目标、遮挡、移动、局部出屏、可信输入、只读输入、过期文档、重定向和 SPA 结果等。
- 连续 20 次导航、观察和提交，每次只提交一次；5 次过期元素编号尝试均在发送输入前拒绝。
- 本地慢资源用例中，背景资源完整加载约 3.03 秒，业务点击完成约 0.33 秒。这是局部测试，不代表所有网站或完整 Agent 任务的提速幅度。
- 安装载荷检查通过，共检查 14,664 个文件；不包含开发环境、账号、Cookie、个人配置或凭据。
- 从该载荷复制出的独立浏览器运行时通过 10 项本地视频播放测试：MP4 H.264/AAC、720p、MSE 合流、MSE 分轨及 VP9/Opus，分别在默认和软件解码配置下检查时间轴、解码帧和跳转。此项不等同于安装成功或外部网站兼容保证。

## 未通过的发布条件

本机安装验收被 Windows 文件操作拒绝阻断，不能声明安装验收通过：

- 外层安装引导程序启动被拒绝后，构建目录中的安装 EXE 消失。
- 单独运行标准 Inno 安装器，在重命名 `browser/d3dcompiler_47.dll` 时返回 Windows 错误 5，安装退出码为 5，并回滚。
- 使用独立安装目录、更换测试临时目录以及此前已发布的 1.0.4 安装内容，均在同一 DLL 处复现。
- 复制载荷进行独立运行时诊断时，原生启动器夹具执行也被 Windows 拒绝。载荷复制不等于安装成功。

本机装有第三方安全软件，但尚未取得足以确认拦截来源的记录；不能将该现象确定归因于某款安全软件，也不能据此认定所有用户电脑都会发生同样的问题。测试未关闭安全软件、添加排除项或修改系统安全策略。

原生页面测试在未展示的测试专用桌面上运行。Windows 拒绝读取当前输入桌面，因此报告明确将输入桌面核验记为不可用，未将其计为已通过。测试不调用桌面切换或全局键鼠输入。

安装器、原生启动器和完整产品首次启动验收通过之前，1.0.5 安装包应保留为发布草稿。不能引用此前版本的视频或产品界面测试作为本版本的通过结果。本轮未调用在线 DSH 模型，不代表完整模型任务成功率。
