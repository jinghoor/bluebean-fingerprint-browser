# 1.0.0 发布测试说明

测试对象为 Windows x64 安装程序。已在本机隔离目录中成功安装，退出码 0，无需重启。具体安装文件数量与逐一 SHA-256 校验结果以该版本的 `acceptance.json` 为准。

通过的检查包括：

- 安装器、启动 EXE 和 Chromium 主图标均与蓝豆 Logo 一致。
- 独立 Python 运行时、产品模块及 HTTP/SOCKS、加密、压缩、时区、Tk 依赖可用。
- Chromium 在开启沙箱时无界面渲染网页成功。
- 清除开发工具 PATH 后，在全新用户数据目录和 pnpm 离线模式下，DSH 首次初始化、蓝豆插件安装及服务健康检查通过。
- 原生启动器在带空格路径中调用随包 `pythonw.exe` 成功。
- 卸载清理已安装程序文件且保留独立用户数据。

## 验证边界

没有在另一台电脑或全新 Windows 虚拟机中实测。为避免干扰桌面，本机自动安装测试使用验收参数，跳过真实桌面/开始菜单快捷方式和 Windows 卸载登记；正常交互安装包含这些步骤。未做完整 GUI 自动化、模型 API 请求或真实账号登录测试。原生启动器检查使用无害脚本夹具，并非完整产品窗口自动验收。

安装器已增加独立的原生启动层。在先前导致安装器无法启动的默认 TEMP/TMP 条件下，修正版自动选择了独立目录，安装成功并返回 0。损坏内嵌载荷的探针测试返回 11，确认校验失败时不会执行载荷。没有修改系统 TEMP 的 ACL；安装结束后本次创建的私有临时目录已清理。
