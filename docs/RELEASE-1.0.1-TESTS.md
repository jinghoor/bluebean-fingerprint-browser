# 1.0.1 发布测试说明

测试日期：2026-11-02。测试平台：本机 Windows x64。

## 安装权限回归

- 最终安装文件的完整性级别为 Medium（SID RID 8192），直接查询 Windows 安全描述符确认，不依赖中文或英文命令输出。
- 测试使用过滤后的 Medium 令牌：管理员组置为仅拒绝、禁用多余权限。安装器实际进程 RID 为 8192。
- 不传 `/ACCEPTANCETEST`，不覆盖 TEMP/TMP，不自定义安装目录；安装至 `%LOCALAPPDATA%\Programs\BlueBean Fingerprint Browser`。
- 安装退出码 0，日志无异常，耗时约 40.95 秒；原生沙箱权限配置约 1.4 秒完成。
- 当前用户卸载登记及版本 1.0.1 正确；桌面、开始菜单快捷方式实际指向安装目录中的 `BlueBean.exe`，图标指向蓝豆 ICO。
- 安装目录和主要可执行文件为 Medium；根目录、主程序、Python 和 Chromium DLL 均具备两组应用包所需的读取/执行权限。
- Low Integrity 启动探针返回 13；该检测发生在解压和运行载荷之前，不弹出静默测试窗口。

## 运行检查

- 13,880 个安装载荷文件逐一 SHA-256 匹配。
- 安装器、启动器、Chromium 内嵌图标匹配蓝豆 Logo。
- 私有 Python、Tk、HTTP/SOCKS、加密、压缩和 IANA 时区依赖可用。
- 清除开发依赖 PATH 后，产品模块导入和开启沙箱的 Chromium 无界面渲染通过。
- 独立数据目录内的 DSH 首次初始化、插件安装和服务检查通过。

## 卸载与恢复

卸载同样使用 Medium 过滤令牌与默认 TEMP，退出码 0，约 2.17 秒完成。程序载荷、测试创建的快捷方式和卸载登记已移除，独立测试数据标记保留。运行检查生成的 303 个字节码缓存由测试收尾逐项清理。测试前存在的桌面快捷方式已按原文件恢复，并核对 SHA-256；没有使用真实账号或修改真实环境数据。

没有在第二台电脑或全新 Windows VM 上实测，没有完成产品 GUI 全流程、真实模型调用或账号登录测试。正常安装采用静默参数，以避免影响桌面操作；这不等同于逐页点击完整安装向导。原生启动器检查使用无害脚本夹具。机器可读结果见 release 的 `acceptance.json`。
