# v1.0.4 发布测试说明

本轮在构建机上使用安装包进行独立安装，所有环境、账号、服务和浏览器数据均为临时测试数据。

- 正常 Windows 用户 Programs 路径静默安装通过，安装退出码为 0；验收模式不改动使用者现有的快捷方式和卸载登记。
- 已安装文件与打包源逐个校验 SHA-256，共 13,886 个文件，无差异。
- 原生启动器、浏览器和安装包均验证为蓝豆图标；安装器与启动器的 Windows 产品版本为 1.0.4。
- 私有 Python、产品模块、DSH 初始化、Chromium 沙箱渲染、Medium Integrity 与沙箱访问权限检查全部通过。
- 首次启动、后台初始化、空环境列表、API Key 输入、助手收放、工具栏开关、环境 API、重启后数据保留等 26 项实际产品检查全部通过。程序在独立 Windows 桌面运行，未切换或操作使用者桌面。
- 本机观测到浏览器就绪约 0.937 秒，后台助手就绪约 2.985 秒，重启浏览器约 0.953 秒。这些数据仅代表此次测试机器。
- 启动、环境状态与代理回归共 87 项通过，包含 16 路并发传输、20 次中继启停。
- 安装版 MP4 H.264/AAC、720p、MSE 合流、MSE 分轨、VP9/Opus 在默认及软件解码路径共 10 项播放检查通过。
- 安装包内容和公开源码检查未发现开发环境列表或当前开发凭据；项目许可及第三方声明随安装包和源码提供。

本轮使用了 `/ACCEPTANCETEST=1`，未覆盖全新实体电脑上的交互式安装向导、桌面快捷方式和卸载登记全流程；此前版本的普通安装登记验证见历史发布说明。本轮验证不代表所有外部网站或第三方服务均可用。

测试还纠正了两处验收夹具问题：受限构建目录不适合模拟正常安装目录；首次设置交互必须在助手实际显示时进行，不能先用“收起”命令隐藏弹窗后再操作。最终报告来自正常用户路径与可见测试面板。
