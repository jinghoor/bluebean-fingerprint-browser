# Platform icons

These assets are bundled into the client by `node lan_seats/scripts/build-icons.cjs`.
No icon service is contacted when the UI renders. The adjacent `manifest.json`
records each icon's upstream source, version, and license.

- Simple Icons 13.0.0: https://github.com/simple-icons/simple-icons/tree/13.0.0,
  CC0-1.0. Original geometry; brand colors applied.
- SVG Logos, Gil Barbara and contributors, via @iconify-json/logos 1.2.18:
  https://github.com/gilbarbara/logos, CC0-1.0.
- Lazada icon: Donnnno and Arcticons contributors, via
  @iconify-json/arcticons 1.2.59, https://github.com/Arcticons-Team/Arcticons.
  Licensed under CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/.
  The stroke was colored orange and set to width 2.4; path geometry is unchanged.
  The distributed Lazada asset and adaptations remain under CC BY-SA 4.0.
- Browser environment and generic website glyphs are project UI assets.

TikTok Shop uses the TikTok brand glyph. Brand names identify account platforms;
ownership of brand marks remains with their respective owners.
